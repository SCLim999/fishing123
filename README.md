# 🏴‍☠️ 宝藏海湾 · 钓鱼机 (Treasure Cove)

街机风格的钓鱼小游戏 —— **一个 click 就开始**，整个游戏就是一个 `index.html`，
没有任何依赖、不用打包、离线也能玩。

**▶️ 在线玩：https://sclim999.github.io/fishing123/**

## 玩法

- 点一下开始，一局 60 秒。
- 点海里任何位置放钩，钩子一直往下沉；**下沉中再点一下就在当前深度开始收线**（不必沉到底）。
- **收线途中碰到的全部串上来**（最多 8 个）—— 所以真正的决策是「挑哪一竖排下钩」。
  串得越多拉得越慢，一串里每一个都算一次连击。
- 每个目标头上写着分数。越大越值钱、拉上来越慢，但**大货会加时间**：
  60 分以上 +1s，150 分以上 +2s，400 分以上 +3s（每局奖励总上限 25s，所以一局最长 85s）。
- **最后 20 秒进入 FEVER**：海水转暖、鱼群刷新翻倍、宝箱和巨兽来得更勤、得分 ×1.5。
  进入后不再发时间奖励，所以 FEVER 永远是「最后一段」，不会被大货把时间顶回去反复开关。
- 连击加成最高 ×2，空钩清零。
- **水里有危险物**，看清了再决定下哪一竖排：
  **水雷 −3 秒**（清连击、画面震一下），**破靴子 0 分**（很沉，白白耗掉收线时间）。
  它们的标签是红/灰色，和金色的分数一眼能分开。
- **每局 3 个随机小目标**（钓 2 只乌贼 / 一次串钩 6 个 / 连击到 10 / 整局不碰水雷…），
  完成加 250~500 分，左上角显示进度，结算列出完成情况。*（仅单人局；联机的分数由服务器结算）*
- **图鉴收集**：15 种钓到过的会在开始画面亮起来，进度存在浏览器里；每局结算列出本局新解锁的。
- **局时可选 30 / 60 / 120 秒**（记在浏览器里）。FEVER 门槛和时间奖励上限按局时缩放：
  30s → FEVER 剩 10s、奖励上限 13s；60s → 20s / 25s；120s → 20s / 50s。
- **本机排行榜**：每个局时档位各留前 5 名（含日期，联机成绩会标「联机」），
  最高分也是**分档记的** —— 30s 和 120s 的成绩没有可比性。
- **分享成绩**：结算按「复制 / 分享成绩」，有系统分享就调系统分享，否则复制到剪贴板
  （分数、战果、完成的任务、图鉴进度、游戏链接）。
- 音效用 WebAudio 现场合成，可静音。
- 操作：鼠标点击 / 手机点屏 / 空格键。
- **全屏**：右上角 ⛶ 或按 **F**（Esc 退出）。全屏后画布内部分辨率会跟着放大，不会变虚；
  iPhone Safari 不给普通元素全屏，那里会自动退回「沉浸模式」（收起标题说明、机台顶满高度）。

## 多人联机

和朋友在**同一片海里抢鱼** —— 鱼被谁先钩到就归谁，右上角实时比分，一局结束按分数排名。

1. 部署一台联机服务器（Cloudflare Worker，约 5 分钟）：见 [`worker/README.md`](worker/README.md)。
2. 在开始画面填一次「联机服务器」地址和昵称，输入房间码，点 **联机开钓**（都会记住）。
3. 或者直接把带参数的链接发给朋友，点开就进同一个房间：
   `?server=wss://<你的-worker>.workers.dev&room=ABCD`

分工：**服务器管世界**（出什么鱼、在哪、归谁、分数、计时、FEVER），
**客户端管手感**（鱼怎么游、钩子怎么动）。鱼的移动不走网络 —— 出生时把
`x / y / vx / life` 一次发下去，两边按同样参数各自推进，所以没有每帧同步、画面不抖；
真正需要仲裁的只有「这条鱼归谁」，那是一条 `grab` 消息，服务器先到先得。
联机时得分在**钩到那一刻**结算（不是拉上岸时）。

**观战模式**：勾上「观战模式」（或链接加 `&spec=1`）进房只看不钓 —— 没有自己的钩子、
不进比分板，能看到所有人的船、鱼线和实时比分；玩家那边会显示「👀 N 人观战」。

**联机局时**由第一个点开始的人决定（30/60/120，非法值回落 60），局中不能改。

服务器断了会自动退回单人，不会卡住。没填服务器地址时，游戏就是纯单机的，和以前一样。

> 注意：把这个页面放在会禁止外连的沙箱里（例如 Claude Artifact）时，WebSocket 会被 CSP 拦掉，
> 只能单人玩。联机请用 GitHub Pages 这类正常托管。

## 图鉴（按深度分层）

| 水层 | 目标（分数） |
|---|---|
| 浅水 | 金币 10 · 小丑鱼 20 · 小蓝鱼 30 · 水母 60 |
| 中层 | 黄金鱼 80 · 河豚 110 · 海龟 200 · 乌贼 240 |
| 深海 | 大红鱼 150 · 剑鱼 320 · 鱼王 400 · 宝箱 500 · 深海灯笼鱼 650 · **深海巨兽 1000** |
| 海底 | 螃蟹 130 |
| 危险物 | 水雷 −3s · 破靴子 0 分 |

每种的行为都不一样：鱼群横向游动，乌贼会突然喷水急冲，海龟慢慢划水，水母一鼓一缩往上浮，
宝箱缓缓上浮，螃蟹在海底横着走、撞边就转身，小鱼常常三条一起成群出现。
深海灯笼鱼头上的灯笼会发光；巨兽收线只有 55 px/s，拉一次要十几秒。

## 本地运行

不需要服务器，直接双击 `index.html` 就行（或 `python3 -m http.server` 后打开）。

## 改鱼种 / 调平衡

`index.html` 里的 `KINDS` 表就是全部配置，一种鱼一行：

```js
squid: { name:"乌贼", score:240, pull:190, depth:[0.35,0.82],
         hw:38, hh:26, lo:36, w:6, art:"squid", move:"jet" },
```

- `score` 分数 · `pull` 收线速度（越小越难拉） · `depth` 出现深度（0 = 水面，1 = 海底）
- `hw`/`hh` 命中半径 · `lo` 分数标签高度 · `w` 出现权重（0 = 由专门的计时器投放）
- `art` 画法（对应 `ART` 表里的函数） · `move` 行为（`swim`/`jet`/`paddle`/`drift`/`crawl`/`rise`/`coin`）

加一种新鱼 = 在 `KINDS` 加一行 + 在 `ART` 加一个小画法函数。
