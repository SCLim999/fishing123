# 🏴‍☠️ 宝藏海湾 · 钓鱼机 (Treasure Cove)

街机风格的钓鱼小游戏 —— **一个 click 就开始**，整个游戏就是一个 `index.html`，
没有任何依赖、不用打包、离线也能玩。

**▶️ 在线玩：https://sclim999.github.io/fishing123/**

## 玩法

- 点一下开始，一局 60 秒。
- 点海里任何位置放钩，钩子一直往下沉；**下沉中再点一下就在当前深度开始收线**（不必沉到底）。
- **收线途中碰到的全部串上来**（最多 8 个）—— 所以真正的决策是「挑哪一竖排下钩」。
  串得越多拉得越慢，一串里每一个都算一次连击。
- 每个目标头上写着分数。越大越值钱、拉上来越慢，但**大货会加时间**：
  60 分以上 +1s，150 分以上 +2s，400 分以上 +3s（每局奖励总上限 25s，所以一局最长 85s）。
- **最后 20 秒进入 FEVER**：海水转暖、鱼群刷新翻倍、宝箱和巨兽来得更勤、得分 ×1.5。
  进入后不再发时间奖励，所以 FEVER 永远是「最后一段」，不会被大货把时间顶回去反复开关。
- **大货会挣扎**：钩到 400 分以上的东西时，收线变成一场小对抗 —— 指针来回跑，
  点在绿区里猛拉一下（收线 ×2.3），点歪就滑一下（×0.35）；每拉中一次绿区变窄、指针变快。
  只影响速度，不会把鱼弄掉，所以联机也能用。
- **每局随机一张地图**：外海 / **珊瑚礁** / **深海沟** / **沉船遗址** / **极地海**。
  地图不只是换皮 —— 它会乘到出鱼权重上，所以**换了海域就得换打法**：
  珊瑚礁小鱼成堆（小鱼占比 44%，几乎不出巨兽鲸鱼）；深海沟灯笼鱼多 6 倍、小鱼只剩 9%；
  沉船遗址金币和危险物都翻倍（金币 23%，水雷破靴子 11%）；极地海鲸鱼最多、暖水小鱼几乎没有。
  海水配色、海底装饰（珊瑚丛 / 石笋 / 沉船残骸 / 浮冰与冰棱）也跟着换，开局左上角报一次地名。
  地图和天色是**两条独立的轴**，所以每局是「地图 × 天色」的组合，海水颜色取两者的中点。
  联机时地图由服务器统一下发，一屋子人同一片海。
- **每局天色不同**：晴天 / 黄昏 / **夜钓** / **暴风雨**。夜里远处的鱼看不清（只有会发光的和分数标签还看得到），
  钩子自带提灯；暴风雨里船摇得厉害、下雨、偶尔打雷。**只影响观感，不动任何数值**；
  联机时天色由服务器下发，一屋子人看到同一片天。
- 连击加成最高 ×2，空钩清零。
- **道具**（钓上来即生效）：🧲 磁铁（附近金币和道具被吸向钩子，6s）、⚓ 大钩（命中范围 ×1.8，8s）、
  ⚡ 浮标（收线 ×1.6，10s）、⏱ 怀表（+5 秒）。生效中左上角显示图标和剩余秒数，大钩会把钩子画大。
- **爆炸互动**：钓走**河豚**会「砰」地炸开，把 170px 内的鱼**震晕 3 秒**（原地不动 = 好钓）；
  钓走**水雷**则把 230px 内的鱼**炸散**。联机时爆点由钓到的人上报、服务器转发，所有人算出同一个结果。
- **鱼阵**：偶尔来一队 9~14 条同深度、同速度的小鱼排成一列 —— 一钩下去能串满上限 8 个。
- **🦈 鲨鱼会吃鱼**：它在海里巡游，盯上 300px 内的小鱼就冲过去一口吃掉 —— 那条鱼是**真的没了**，
  你少一个目标。但每吃一条，鲨鱼自己就 **+70 分并且长大一圈**（基础 380，最多吃 6 条 → 800 分），
  头顶的数字是实时的。所以它是一场划算与否的赌博：**等得越久它越值钱，小鱼也被它吃得越少**。
  吃到 400 分以上就会触发拉扯 QTE。只吃小鱼（小蓝鱼、小丑鱼、黄金鱼、大红鱼、水母、乌贼），
  宝箱、道具、水雷、海龟、巨兽一口都不碰；已经上钩的东西也抢不走。
  *（仅单人局 —— 联机的世界由服务器仲裁，让客户端自行删鱼会两边对不上，所以服务器鱼表里没有它）*
- **水里有危险物**，看清了再决定下哪一竖排：
  **水雷 −3 秒**（清连击、画面震一下），**破靴子 0 分**（很沉，白白耗掉收线时间）。
  它们的标签是红/灰色，和金色的分数一眼能分开。
- **每局 3 个随机小目标**（钓 2 只乌贼 / 一次串钩 6 个 / 连击到 10 / 整局不碰水雷…），
  完成加 250~500 分，左上角显示进度，结算列出完成情况。*（仅单人局；联机的分数由服务器结算）*
- **🗺 藏宝图碎片 → SUPER FEVER 关卡**：海里偶尔会出**地图碎片**（本身也值 120 分），
  一局一局攒，**集齐 5 片**开始画面就出现金色的「进入 SUPER FEVER」按钮：
  > **宝藏秘境**：固定 45 秒，一张平时抽不到的金色地图；**全程 FEVER，得分 ×3**
  > （FEVER 的 ×1.5 再 ×2）；**没有水雷和破靴子**；宝箱和深海巨兽成堆地出，小鱼几乎不出。
  > 碎片在**开局那一刻就扣掉**（中途刷新不会白送一次），打完回到普通局重新攒。
  仅单人 —— 联机的鱼由服务器发，它的鱼表里没有碎片。
- **图鉴收集**：29 种钓到过的会在开始画面亮起来，进度存在浏览器里；每局结算列出本局新解锁的。
- **结算页分三栏**：「战果」是分数、任务、成就、排行；**「钓到的鱼」**列出这一局的每一种收获；
  **「🛠 造船厂」**可以当场花刚赚到的金币升级，不用退回开始画面。
  战果那一栏在金币行下面还会**问一句要不要升级**：钱够了就高亮显示「够钱升级了：绞盘 → 1 级（400 金）」
  并给一个「去升级」按钮直接跳过去；钱不够就说「再攒 33 金就能升鱼线了」，让你知道再打一局能换到什么。
  两处造船厂共用同一个渲染函数，买完一起刷新。
  「钓到的鱼」那一栏：缩略图 + 数量 + 得分 + 一句冷知识（按分数从高到低排）。缩略图**不是图片文件**，
  是拿画海里那条鱼的同一套 `ART` 函数现画到 62×62 小画布上的，所以永远和游戏里长得一样，
  也不增加任何外部资源。真实物种写的是真事，金鱼 / 鱼王 / 巨兽这类机台角色按传说和玩法写，
  不混成一副科普的样子。文案在 `FACTS` 表里，中英各一份。
- **🛠 造船厂（升级船）**：每局结算按 **12 分 = 1 枚金币**折算，金币在开始画面的造船厂里买升级，
  **跨局累积、存在浏览器里**。5 项，每项直接改真实数值：
  🧵 鱼线 收线速度 +8%/级（5 级）· 🪝 鱼钩 命中范围 +9%/级（5 级）·
  ⚙️ 绞盘 一钩多串 1 个/级（3 级，8 → 11）· ⛵ 船体 每局 +3 秒/级（4 级）·
  🍀 运气 300 分以上的大货出现率 +14%/级（4 级，小鱼和金币权重一点不动）。
  **联机里也生效** —— 但只有「改我自己」的那三条：
  > 🧵 鱼线 / 🪝 鱼钩 / ⚙️ 绞盘 改的是我这根线怎么动，别人的世界一点不受影响，所以联机照常算，
  > 联机局也照常发金币。
  > ⛵ 船体（局时）和 🍀 运气（出鱼权重）改的是**整个房间共用的世界** —— 倒计时和出什么鱼
  > 由服务器统一发给所有人，没法只给一个人加时间、只给一个人多出鲸鱼，所以联机里那两条不算，
  > 面板上标了「仅单人」。
  > **每日挑战全部不算**：全球同一片海比分数，装备不同就没得比了；那种局也不发金币。
  > 代码里靠 `upgOn(id)` 统一判定（`ROOM_WIDE` 那一组联机时自动归零），
  > 而不是每处效果各写一遍条件然后漏掉一处。
- **成就 14 项**（跨局累积，存在浏览器里）：一钩串满 8 个、拉上巨兽、连击 15、单局 5000 / 10000 分、
  整局不碰水雷且过 2000、夜钓 3000、暴风雨 3000、一局用齐 4 种道具、集齐图鉴、一局 3 个宝箱、
  **钓上一条吃饱的鲨鱼**、联机拿第一、完成 5 次每日挑战。开始画面显示 `成就 n/14`，局末新解锁的会一条条弹出来。
  判定只看**这一局**的统计，不翻历史。
- **局时可选 30 / 60 / 120 秒**（记在浏览器里）。FEVER 门槛和时间奖励上限按局时缩放：
  30s → FEVER 剩 10s、奖励上限 13s；60s → 20s / 25s；120s → 20s / 50s。
- **每日挑战**：开始画面点「每日挑战」—— 用当天日期播种，**全世界当天是同一片海**
  （同样的鱼群顺序、同样的天色、同样的任务），局时固定 60s，比谁分高。
  完全不需要服务器；排行榜里标 ⭐，菜单显示「今日最佳」和挑战次数。
- **本机排行榜**：每个局时档位各留前 5 名（含日期，联机成绩会标「联机」），
  最高分也是**分档记的** —— 30s 和 120s 的成绩没有可比性。
- **分享成绩**：结算按「复制 / 分享成绩」，有系统分享就调系统分享，否则复制到剪贴板
  （分数、战果、完成的任务、图鉴进度、游戏链接）。
- **成绩图**：结算按「保存成绩图」现画一张 900×560 的图 —— 机台木框、天空海水、大分数、
  本局战果、完成的任务、图鉴与成就进度，右边用本局钓到的鱼当插图。
  手机上走系统分享（可直接发到聊天里），电脑上直接下载成 PNG。
  被嵌在别人页面里（iframe / 沙箱预览）时下载会被拦掉，这时改成把图铺满屏幕，长按或右键另存为。
- 音效用 WebAudio 现场合成，可静音。
- **背景音乐**：右上角 🎵 开关（默认关，选择记在浏览器里）。曲子是
  **Aetheric —「Snap Crackle」**（[Free To Use](https://freetouse.com)），`assets/bgm.mp3`，
  90 秒循环，**只在真的打开音乐时才去下载** —— 不开音乐的人一个字节都不用付。
  **FEVER 时播放速度 ×1.12**；锁屏会暂停，解锁从原处接着放。
  取不到文件时（离线、404、被 CSP 拦掉）自动退回一段 WebAudio 现场合成的海盗小调
  （16 拍两声部循环，FEVER 提速 15%），音乐不会哑掉。
- **中英双语**：右上角 `中 / EN` 按钮随时切换，选择记在浏览器里；首次打开跟随浏览器语言
  （`zh*` → 中文，其余 → 英文）。鱼名、任务、提示、结算、分享文本全部跟着切。
- 操作：鼠标点击 / 手机点屏 / 空格键。联机时画面下沿会出现一排按钮
  （4 个表情 + 💥 撞船），键盘上对应 **1~4** 和 **R** —— 手机没有键盘，按钮才是主入口。
- **锁屏**：右上角 🔒 随时锁上，要输密码才能继续（密码在 `index.html` 的 `LOCK_PW`，
  默认 `fish@123`）。锁着的时候整个世界冻住 —— 倒计时不走、鱼不动，所以中途锁屏不会白扣时间；
  点屏和快捷键也都不响应。解锁记在 `sessionStorage`，同一次浏览器会话里不用反复输，
  浏览器整个关掉就重新锁上；手动按 🔒 也会立刻要求重新输入。联机时锁屏会退出房间
  （本地冻住而服务器还在跑，留着解锁后必然错位）。
  > ⚠️ 这是一道**简单的门，不是安全措施** —— 页面是纯静态的，密码就写在文件里，
  > 看一眼网页源码就能拿到。用途是「不知道密码的人打不开来玩」，别拿它保护任何要紧的东西。
- **全屏**：右上角 ⛶ 或按 **F**（Esc 退出）。
  - 全屏后**海面会按屏幕比例加宽**（逻辑宽度 600 → 最多 2200），16:9 能填满约 99% 的宽度，
    21:9 约 90%；出鱼密度和鱼群上限跟着宽度缩放，加宽后不会显得空。
  - 内部分辨率按显示尺寸 × 像素密度重算（受 620 万像素预算约束），所以放大后不会变虚也不掉帧
    —— 静态背景（天空、海水渐变、光柱、海底）烘到离屏画布，每帧只贴一次。
  - **联机时固定回标准宽度**：所有人必须是同一片海才公平，所以联机全屏是竖屏机台居中、两侧留边。
  - **iPad / iPhone Safari** 上元素全屏时常不可用：iPhone 根本不支持，iPad 上
    `webkitRequestFullscreen` 这个方法**存在**、`fullscreenEnabled` 却可能是 false，
    调下去既不报错也不进全屏。所以按钮点完会**回头验一次**真的进去了没有，没进就自动退回
    「沉浸模式」（收起标题和说明，机台铺满可见区域，实测 iPad 横屏 99% 宽 / 93% 高）——
    不会出现「点了按钮什么都没发生」。
  - 高度用 `100dvh`（不认识就退回 `100vh`）：iOS 的 `100vh` 是不含工具栏的大高度，
    直接用会把机台底部顶出屏幕。另外还盯着 `visualViewport` 的 resize —— iOS 收起地址栏时
    不一定发 window 的 resize。
  - 内容比机台高时（iPad 横屏、矮窗口），遮罩层用两个可压缩的伪元素当弹簧来居中，
    而不是 `justify-content:center` —— 后者在内容溢出时会把顶部裁掉且滚不上去。

## 多人联机

和朋友在**同一片海里抢鱼** —— 鱼被谁先钩到就归谁，右上角实时比分，一局结束按分数排名。

### 一次性准备：部署联机服务器（约 5 分钟，需要一台装了 Node 的电脑）

```bash
git clone https://github.com/SCLim999/fishing123
cd fishing123/worker
npx wrangler login       # 浏览器里授权 Cloudflare 账号（没有就现注册，免费）
npx wrangler deploy
```

最后会打印出地址，例如：

```
https://treasure-cove-mp.你的子域.workers.dev
```

浏览器打开它，看到一行中文提示就说明服务器活着。**这一步只做一次**，之后一直可用。

> **只有手机、装不了 Node？** 让 GitHub 代跑：加两个仓库 Secret，然后在 Actions 里点一下
> **Deploy multiplayer worker** 就部署好了，全程手机浏览器。步骤见 [`worker/README.md`](worker/README.md)。

### 每次一起玩

服务器地址**已经内置**（`index.html` 里的 `DEFAULT_SERVER`），所以「联机服务器」那一栏
打开就是填好的，一般不用管它。取值优先级：链接里的 `?server=` > 浏览器记住的 > 内置默认值。

**做法 A：发链接（最省事）**

只要带房间码，对方点开就直接进房：

```
https://sclim999.github.io/fishing123/?room=ABCD&name=Ann
```

- `room=` **必须一样**，随便起，例如 `ABCD`
- `name=` 各人不同，就是比分板上的昵称
- 想只看不钓，加 `&spec=1`
- 想用别的服务器就加 `&server=…`（`https://` 或 `wss://` 都行，游戏会自动转成 `wss://…/room`）

**做法 B：手填**

打开 https://sclim999.github.io/fishing123/ → 填昵称、填同一个房间码 → 点 **联机开钓**
（服务器栏已经预填）。填过的地址和昵称都会记住。

> 自己 fork 的话，把 `index.html` 里的 `DEFAULT_SERVER` 改成你 `wrangler deploy` 得到的地址
> —— 或者留空，那就退回「必须手填」。内置的是公开地址，等于谁拿到链接都能用你的
> Cloudflare 额度；房间之间是隔离的（房间码不同就互不干扰），但额度是共用的。

进去后**任何人点一下画面就开局**，第一个点的人决定这局多长（30 / 60 / 120 秒）。

### 只想在同一个 WiFi 下玩（不用 Cloudflare）

用仓库里自带的本地服务器：

```bash
npm install ws
node server/local.mjs              # ws://<本机IP>:8787
python3 -m http.server 8000        # 另开一个终端，在仓库根目录
```

手机 / 别的电脑打开 `http://<本机IP>:8000/?server=http://<本机IP>:8787&room=ABCD&name=Bob`。

> ⚠️ 这里游戏页面要走 **http**（本机那个 8000），不能用 GitHub Pages 的 https —— 浏览器会拦掉
> https 页面里的 `ws://` 明文连接（混合内容）。

分工：**服务器管世界**（出什么鱼、在哪、归谁、分数、计时、FEVER），
**客户端管手感**（鱼怎么游、钩子怎么动）。鱼的移动不走网络 —— 出生时把
`x / y / vx / life` 一次发下去，两边按同样参数各自推进，所以没有每帧同步、画面不抖；
真正需要仲裁的只有「这条鱼归谁」，那是一条 `grab` 消息，服务器先到先得。
联机时得分在**钩到那一刻**结算（不是拉上岸时）。

**合作模式**：勾上「合作模式」开局，全房间**共用一个目标分**（按人头和局时缩放：
每人每 60 秒 2600 分），左上角显示 `队伍 x / y`，局末一起赢或一起输。
模式由**第一个点开始的人**决定；中途加入的人跟着房间走，勾选框会自动同步。

**快捷表情**：联机时按 **1~4**，或点画面下沿那排按钮，发 👍 😂 🎣 😱，飘在自己船的上方，
全房间都看得到（服务器按人 700ms 限一次，焦点在输入框里时不触发）。观众也能发。

**墨囊 🌫**：只在联机局出现的捣蛋道具 —— 谁钓到它，**别人**的画面会被几坨墨糊住约 3 秒
（钓到的人自己不受影响）。

**撞船 💥**：船与船之间可以互相使坏。**点对手的船**（水面上那条窄带），或点画面下沿的
**💥 按钮** / 按 **R** 撞最近的一条，就冲过去撞一下 ——

- 撞得到的时候，对方船头会闪一个 💥，不用记规则，看得见才知道现在能撞；
- 条件：**自己的线得先收上来**（撞人的时候你没在钓鱼），对方要在 **200px** 以内，冷却 **5 秒**；
- 挨撞的人：钩子被往旁边拽 **72px**（本来瞄着的那条鱼就跑了）、收线速度掉到 **0.4×** 约 1 秒、
  正在拉扯的大货会脱力，这一秒里也抛不出新的钩；
- **分数不动** —— 已经上钩的照样算他的，干扰的是「下一条抢不抢得到」。

服务器只做两件事：确认「谁撞了谁」，以及卡冷却（同一个人 4.5 秒才能再撞一次，
同一个人挨完撞有 2 秒无敌，免得被一屋子人围殴）—— 客户端改了也刷不了屏。
观众撞不了人，也不会被撞。一局撞开对手 3 次有成就「撞开对手 3 次」。

**缠线 🪢**：不用按键的互相干扰 —— 两根线离得太近（横 34px、纵 64px 以内）就会缠上，
**双方**收线都掉到 0.55×，同时互相顶开，所以不会永远卡死。交叉处会打一个转动的结。
每条船在海面上按自己的相位来回开（不给相位差的话，一屋子人会叠在同一个浪头上）。

**船位和钓点是两回事**：`hook` 消息除了钩子坐标还带一个 `s`（船在哪），所以别人的船画在
船位上、鱼线从船头斜拉到钓点 —— 撞船撞的是船，不是他的浮标。观众没有船，服务器压根不把
他们放进钩子广播里。

**观战模式**：勾上「观战模式」（或链接加 `&spec=1`）进房只看不钓 —— 没有自己的钩子、
不进比分板，能看到所有人的船、鱼线和实时比分；玩家那边会显示「👀 N 人观战」。

**联机局时**由第一个点开始的人决定（30/60/120，非法值回落 60），局中不能改。
**天色和地图**都由服务器随 `start` 下发，中途加入的人从 `welcome` 里拿到当前的。
地图表在客户端（`MAPS`，管名字和画法）和服务器（`MAP_W` / `MAP_MUL`，管挑哪张和出鱼权重）
各有一份 —— **改了要两边一起改**。

服务器断了会自动退回单人，不会卡住。没填服务器地址时，游戏就是纯单机的，和以前一样。

> 注意：把这个页面放在会禁止外连的沙箱里（例如 Claude Artifact）时，WebSocket 会被 CSP 拦掉，
> 只能单人玩。联机请用 GitHub Pages 这类正常托管。

## 改鱼种 / 调平衡

`index.html` 里的 `KINDS` 表就是全部配置，一种鱼一行：

```js
squid: { name:"乌贼", score:240, pull:190, depth:[0.35,0.82],
         hw:38, hh:26, lo:36, w:6, art:"squid", move:"jet" },
```

- `score` 分数 · `pull` 收线速度（越小越难拉） · `depth` 出现深度（0 = 水面，1 = 海底）
- `hw`/`hh` 命中半径 · `lo` 分数标签高度 · `w` 出现权重（0 = 由专门的计时器投放）
- `art` 画法（对应 `ART` 表里的函数） · `move` 行为（`swim`/`jet`/`paddle`/`drift`/`crawl`/`rise`/`coin`/`hunt`）
- 身价会变的只有鲨鱼：凡是问「这东西值多少」的地方都走 `itemScore(it)`，不要直接读 `kind.score`
- 出鱼权重是 `weightOf(k)` = `KINDS[k].w × 当前地图的倍率`，别直接读 `KINDS[k].w`

## 改地图

`index.html` 里的 `MAPS` 一张图一行：`w` 挑中的权重、`floor` 海底装饰（`weed`/`coral`/`rock`/`wreck`/`ice`）、
`sea` 海水三段配色（可省，省了就用天色自己的）、`mul` 出鱼权重倍率（没写的种类 = 1，写 0 = 这片海不出）、
`add` 加法项（给基础权重是 0、平时靠专门计时器投放的宝箱和巨兽用 —— 乘法怎么乘都还是 0）。
`w:0` 的地图永远不会被随机抽到（宝藏秘境就是这样，只有 SUPER FEVER 关卡会去）。
海底装饰的画法在 `paintFloor()` 里，全部烘进背景，不花运行时。
**联机也要改的话**，`server/room.mjs` 里的 `MAP_W` / `MAP_MUL` 要同步。

加一种新鱼 = 在 `KINDS` 加一行（含 `en` 英文名）+ 在 `ART` 加一个小画法函数。

## 改文案 / 加语言

所有给玩家看的文字都在 `index.html` 顶部的 `I18N` 表里，`zh` 和 `en` 各一份，
代码里一律用 `t("key", { 变量 })` 取，不写死任何一种语言。

- 静态 HTML 用 `data-i18n="key"`（或输入框的 `data-ph="key"`）标注，切换时由 `applyLang()` 整页重刷。
- 鱼名走 `kindName(id)`，取 `KINDS[id].en` 或 `.name`。
- 任务文案在 `MISSIONS` 每条的 `zh` / `en` 字段上（语序差别大，逐条写比套模板更自然）。

要加第三种语言：在 `I18N` 里加一份同样键名的表，再把 `btn-lang` 的两态切换改成轮换即可。
